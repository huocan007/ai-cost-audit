必须修复（准确性 / 信任）

CriticalHero 终端演示的命令在真实仓库里不存在
index.html 行 295–307 ｜ 仓库 tool/ai_cost_audit.py 行 14–16、134–155

Hero 终端展示：

  • pip install ai-cost-audit — 实际仓库 README 明确写"无需 pip，单文件标准库"，且无 PyPI 包。客户执行会失败。
  • ai-cost-audit --logs july.jsonl — 真实 CLI 是 python ai_cost_audit.py audit --prompt-tokens 50e6 --completion-tokens 20e6 --current gpt-4o，既无 --logs 也无"读日志"功能（它吃 token 计数，不是日志文件）。
  • 终端里的英文输出格式，与实际代码打印的中文"AI 成本审计结果"也不一致。

为什么严重： 这正是你卖的信任——"免费、可验证、不编数字"。客户点 "Try the free CLI" 后按 Hero 照做却报错，第一印象直接崩。

修复方向： 让 Hero 终端、README、真实代码三者一致。最小改动：把 Hero 命令改成真实命令 python ai_cost_audit.py audit --prompt-tokens 50e6 --completion-tokens 20e6 --current gpt-4o，并把输出改成工具真实打印的内容（或先让工具输出英文）。更彻底：把工具做成真正的 pip install ai-cost-audit 并补 PyPI 发布/或把 README 改成 git clone 且 Hero 同步。

Major工具内嵌价格含未核实/虚构模型

CLI 的 PRICING 字典里混入了未在公开页核实的模型（代码注释自己也标"推测"）。落地页计算器用的是另一套真实价格（$15/$75 = 真实 Claude 3 Opus），所以页面本身没骗人；但若客户跑 CLI 的 gen-config 或看工具源码，会看到这些虚构项，削弱"我们只用核实价"的承诺。仓库 kimi-k3 也标注"未核到精确数"。

修复： 工具只保留已核实模型；未核实的（gpt-5.6、claude-opus-4.8、kimi-k3）要么删除，要么加醒目"估算、成交前须核最新价"警告并排除出默认路由。

Major"PayPal（个人账户）"措辞削弱信任
index.html 行 693

"Payment via PayPal (personal seller account) for early engagements." 对西方企业客户，"personal seller account" 信号是"个人非正式、可能触发 PayPal 资金冻结/无企业买家保护"。

改为： "Payment via PayPal or bank transfer." 并建议注册 PayPal Business 账户；如暂用个人户，页面不要主动暴露"personal"。
Major联系表单无明确成功态
index.html 行 732–771

提交后仅按 redirect 跳回 #contact，无"已收到，2 个工作日内回复"的内联提示，整页刷新体验生硬，且客户不确定是否发送成功。

修复： 加一小段 JS：拦截提交→显示"Thanks — we'll reply within 2 business days"内联成功块，避免硬刷新。Web3Forms 支持 AJAX 返回。
Minor缺 favicon 与 Open Graph / Twitter 卡片
index.html <head> 行 4–10

无 favicon、无 og:title/description/image。在 LinkedIn / X 分享时链接预览丑（灰块+裸 URL），而社媒分享正是获客主渠道。

修复： 加 <link rel="icon">（可用现有徽标 SVG 转 ico）与一套 OG 标签（含一张 1200×630 的预览图，建议用架构图或 Before/After 截图）。
