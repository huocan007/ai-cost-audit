What does “cheapest” miss?

Price is not capability. Three caveats change the math in 2026:

1. Peak-hour surcharges

DeepSeek introduced peak/off-peak pricing in July 2026: V4 Flash input doubles during 09:00–12:00 and 14:00–18:00 (Beijing time) — from $0.14 to $0.28 input, $0.28 to $0.56 output. A cost router should shift load off peak windows.

2. The “budget” label expired on some models

Kimi K3 (released 2026-07-16) lists at $3.00 / $15.00 — 3.2× its predecessor K2.6 on input and 3.75× on output (Tokencost analysis ↗). Treat “cheap Chinese model” as a per-model fact, not a region assumption.

3. Quality still varies by task

For frontier coding and complex agentic work, Claude Sonnet 4.6 / Opus 4.8 and GPT-4.1 still lead verified benchmarks. The winning pattern is routing by task: budget models for classification, extraction, and high-volume chat; frontier models only where quality is load-bearing.

Is it safe to route to low-cost models?

Yes — with one hard rule on data residency. Low-cost inference is concentrated in Asia (DeepSeek, Kimi), while Western and self-hosted tiers exist for sensitive data.

Compliance guardrail: Do not route EU user PII or regulated data through Asia-region endpoints. Keep a Western-cloud or self-hosted tier for that traffic. This is a data-residency requirement, not a model-quality claim.

A proper cost-routing gateway (e.g. LiteLLM) lets you set per-route residency policies so the cheap model is used only where the data is allowed to go.

Frequently asked questions

What is the absolute cheapest LLM in 2026?

DeepSeek V4 Flash, at $0.14 per 1M input and $0.28 per 1M output tokens (standard, non-peak pricing, verified 2026-07-27 against the official DeepSeek pricing page). Cache-hit input drops to $0.0028 per 1M. Note peak-hour surcharges double price during China business hours.

How much can I save by routing LLM traffic?

Teams that route non-frontier tasks to low-cost models typically report 70–90% lower API bills with no prompt changes. The extreme case: output on Claude Opus 4.8 ($25/1M) vs DeepSeek V4 Flash ($0.28/1M) is an 89× difference. Caching and batching narrow it but the order of magnitude holds.

Is DeepSeek safe for EU or regulated user data?

It depends on the route. Asia-region endpoints are not appropriate for EU PII or regulated data. Use a Western-cloud or self-hosted tier for that traffic, and configure your gateway with per-route data-residency policies. This is a compliance requirement, not a statement about model capability.

Are these prices stable?

No. LLM API prices moved 60–80% lower on average between early 2025 and mid-2026, but individual models also rose (e.g. Kimi K3 tripled K2.6's rate card). Always verify against the official pricing pages linked in the table above before making procurement decisions.
